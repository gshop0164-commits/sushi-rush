Sushi Rush — an original sushi bar cooking game built for the make.fun best cooking game bounty. One chef, one 150-second shift: take orders from the ticket rail, grab rice, nori and fish, roll maki on the bamboo mat, slice it on the board, assemble plates, and send them down the conveyor before the customers walk out. 6 ingredients, 6 recipes, growing order pressure, combo multipliers and speed bonuses.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD / arrow keys or click, use stations with E, Space to start, P to pause.
